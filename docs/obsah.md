# stiborsky.cz website

DevOps, infrastruktura a provoz aplikací. Návrh, automatizace a dlouhodobá správa.

## Co nabízím

### Kubernetes, cloud a CloudNative
- správa a provoz aplikací na AWS či Google Cloud
- instalace, konfigurace a správa Kubernetes clusterů (managed i self-hosted)
- provoz k8s na vlastní infrastruktuře (Proxmox, Talos, Cluster API)
- implementace GitOps řešení (FluxCD, Atlantis)
- konzultace

### Proxmox
- instalace a správa
- HA řešení, CEPH, PBS
- automatizace, monitoring, aktualizace
- migrace na Proxmox

### Správa serverů
- správa, dohled a provoz malých a středních serverových řešení na GNU/Linux
- webové servery nebo VPS, emailové servery, filestorage, aplikační servery

### IaC a automatizace
- Terraform / OpenTofu, Ansible, Packer
- GitOps pro infrastrukturu (Atlantis, FluxCD, Crossplane)
- automatizace závislostí a supply-chain security (Renovate)

### CI/CD
- návrh a provoz pipeline jako kódu (Jenkins, GitLab CI)
- automatizované buildy, deploye a testování

### Monitoring a observability
- Grafana, Prometheus, Loki, Tempo, Alloy, Zabbix
- dashboardy, alerting, oncall a SLO

### Bezpečnost, secrets a identita
- HashiCorp Vault, External Secrets
- SSO / OIDC (Keycloak), správa TLS certifikátů (cert-manager)
- VPN, bastion, hardening

### Databáze a datové platformy
- PostgreSQL (vč. HA, replikace a zálohování), MySQL, Redis
- ClickHouse, OpenSearch, Solr, Kafka, object storage

### AI / ML infrastruktura
- provoz LLM (vLLM), vektorové databáze (Milvus), GPU nodes
- observability pro LLM aplikace (Langfuse)

### Migrace
- z cloudu na vlastní infrastrukturu (a opačně)
- migrace mezi Kubernetes clustery vč. plánu, cutoveru a rollbacku
